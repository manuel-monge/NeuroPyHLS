# Literature database

A structured extraction of the CAP26 literature on neural-signal processing and its hardware implementations: spike detection and sorting, compression, decoding, closed-loop systems, and seizure/LFP processors. The 56 papers were read in full.

| Table | One row per | Use |
|---|---|---|
| `papers` | paper | bibliography, category, platform, species, validation |
| `hardware` | implemented design | power, area, channels, process node, FPGA resources |
| `algorithms` | algorithm block in a pipeline | task, family, learning mode, causality |
| `metrics` | reported number | accuracy, latency and energy comparisons |
| `datasets` | dataset used | which recordings and species the evaluations rely on |

The tables are kept in the project's document store, alongside the narrative literature review. Summary figures will be published here as the analysis matures.
